POTENTIAL

Powerful, Open-Source UCI Chess Engine optimized for modern architectures.

Try Online View on GitHub

Technical Excellence

Built from the ground up for speed, accuracy, and scalability.

Advanced Search

Core techniques include PVS, Iterative Deepening, Transposition Tables, and aggressive pruning (LMR, NMP, Futility).

Engine Strength

Validated via CCRL 40/15 and Blitz rating lists, demonstrating competitive performance against established engines.

Modern Architecture

Written in C with a high-performance bitboard core, optimized for SSE/AVX2 SIMD instructions and WebAssembly.

UCI Compatibility

Full support for the Universal Chess Interface protocol, compatible with all major GUIs like Arena and CuteChess.

Build From Source

$ git clone https://github.com/ProgramciDusunur/Potential.git
$ cd Potential/src
$ make -j8
$ ./Potential
